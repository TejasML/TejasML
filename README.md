## About Me

I am a fresh Data Science graduate with a strong interest in Data Engineering and the Microsoft Azure ecosystem. My focus lies in building efficient ETL/ELT pipelines, designing scalable data architectures, and working with cloud-based analytical platforms.

I am currently deep-diving into **Azure Databricks**, **Medallion Architecture** (Bronze, Silver, Gold layers), and cloud orchestration to transition complex analytical workloads into modern distributed environments. I hold the **Microsoft Certified: Azure Data Fundamentals (DP-900)** certification and am currently preparing for the **Microsoft Certified: Fabric Analytics Engineer Associate (DP-600)**.

I also explore Machine Learning and Deep Learning — you can find my AI projects on Hugging Face and Kaggle.
